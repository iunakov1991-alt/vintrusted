# 🚀 MONSTER 8.0 Dashboard

Полнофункциональный дашборд для управления MONSTER 8.0.

## ✨ Возможности

- 📊 **Визуализация стратегии** — диаграммы выполнения и прогресса
- 📄 **Статистика страниц** — количество EN/ES страниц в проде
- ⚙️ **BPG статус** — блоки на подходе (Background Prep)
- 🎮 **Управление** — запуск/остановка оркестратора
- 📋 **Логи** — логи в реальном времени
- 💡 **Идеи самообучения** — поле для предложений по улучшению

## 🚀 Запуск

```bash
npm run monster8:dashboard
```

Или напрямую:

```bash
node monster-8.0/dashboard/server-8.0.js
```

Откройте в браузере: **http://localhost:3001**

## 📋 API Endpoints

### GET /api/status
Полный статус системы (страницы, BPG, оркестратор, стратегия)

### GET /api/pages
Статистика страниц (EN/ES/Total)

### GET /api/bpg
Статус BPG (блоки, готовность, логи)

### GET /api/logs
Логи оркестратора

### POST /api/orchestrator/start
Запуск оркестратора

### POST /api/orchestrator/stop
Остановка оркестратора

### GET /api/orchestrator/status
Статус оркестратора (running/stopped, PID)

### GET /api/strategy
Текущая стратегия (фаза, режим, пороги)

### POST /api/learning-ideas
Добавить идею для самообучения

### GET /api/learning-ideas
Получить список идей

## 🔧 Настройка

Порт по умолчанию: `3001` (можно изменить через `MONSTER8_DASHBOARD_PORT`)

```bash
export MONSTER8_DASHBOARD_PORT=3002
npm run monster8:dashboard
```

## 📊 Компоненты

### Strategy Visualization
- Линейный график роста EN/ES страниц
- Текущая фаза (en_only/mixed/es_focus)
- Режим длины (short/long)
- Пороги

### Pages Statistics
- Количество страниц по языкам
- Круговая диаграмма распределения
- Общее количество

### BPG Status
- Количество готовых блоков
- Статус готовности
- Прогресс-бар

### Orchestrator Control
- Кнопки Start/Stop
- Статус и PID процесса

### Logs
- Логи в реальном времени (WebSocket)
- Фильтрация (all/info/warn/error)
- Автопрокрутка

### Learning Ideas
- Форма для добавления идей
- Приоритеты (low/medium/high)
- Список сохраненных идей

## 🔌 WebSocket Events

- `status:update` — обновление статуса (каждые 2 секунды)
- `log` — новый лог
- `orchestrator:stopped` — оркестратор остановлен
- `learning-idea:added` — добавлена новая идея

## 🎯 Использование

1. **Запустите дашборд:**
   ```bash
   npm run monster8:dashboard
   ```

2. **Откройте в браузере:**
   ```
   http://localhost:3001
   ```

3. **Управляйте оркестратором:**
   - Нажмите "Start" для запуска
   - Нажмите "Stop" для остановки

4. **Наблюдайте за прогрессом:**
   - Страницы обновляются автоматически
   - Логи появляются в реальном времени
   - Диаграммы обновляются каждые 2 секунды

5. **Добавляйте идеи:**
   - Введите идею в поле "Learning Ideas"
   - Выберите приоритет
   - Нажмите "Submit"

## 🐛 Отладка

Проверьте логи сервера в консоли. Если порт занят:

```bash
lsof -i :3001
kill -9 <PID>
```
