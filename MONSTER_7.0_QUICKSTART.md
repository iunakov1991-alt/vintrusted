# 🚀 MONSTER 7.0 — QUICK START

**Платформа:** MacBook Air M1 8GB  
**Принцип:** Запуск ТОЛЬКО через Dashboard

---

## 📋 УСТАНОВКА

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка конфигурации

Файл `config/monster.config.json` уже настроен для M1.

### 3. (Опционально) Настройка локального AI

Если хотите использовать локальный AI (Ollama):

```bash
brew install ollama
ollama pull phi3
```

Затем в `config/monster.config.json`:
```json
{
  "modules": {
    "aiKnowledgeCore": {
      "localAI": true,
      "model": "phi3"
    }
  }
}
```

## 🔧 УСТРАНЕНИЕ ПРОБЛЕМ

### Проблема: Dashboard не запускается

**Решение:**
```bash
# Проверьте порт
lsof -i :3000

# Если занят, измените в config/monster.config.json
{
  "dashboard": {
    "port": 3001
  }
}
```

### Проблема: Модуль не запускается

**Решение:**
- Убедитесь, что запускаете через Dashboard
- Проверьте логи в консоли сервера
- Используйте **SELF-REPAIR** для автоматического исправления

### Проблема: Превышение памяти

**Решение:**
- Система автоматически ограничивает использование памяти
- Используйте **STOP** для остановки задач
- Подождите завершения текущих задач
