## 📊 Как это работает:

```
1. Пользователь заходит на главную страницу
   ↓
2. JavaScript проверяет cookie 'ab_variant'
   ↓
3. Если нет - случайно выбирает 'light' или 'dark'
   ↓
4. Сохраняет в cookie на 30 дней
   ↓
5. Применяет стили (добавляет класс к body)
   ↓
6. Отправляет в dataLayer: { event: 'ab_test_view', ab_variant: 'light' }
   ↓
7. При клике на форму: { event: 'ab_test_click', ab_variant: 'light' }
   ↓
8. При покупке: { event: 'purchase', ab_variant: 'light', value: 3.00 }
```

## 📈 Как анализировать:

### В GA4:
1. **Explorations** → Создать новый отчет
2. Dimension: `ab_variant`
3. Metrics: `Event count`, `Conversions`, `Revenue`
4. Фильтр: Events = `ab_test_view`, `purchase`

### Метрики для сравнения:
- **CTR:** `ab_test_click / ab_test_view * 100%`
- **Conversion Rate:** `purchases / ab_test_view * 100%`
- **Revenue:** Сумма `value` в событиях `purchase`
- **CPA:** `Ad Spend / Purchases` (по вариантам)
