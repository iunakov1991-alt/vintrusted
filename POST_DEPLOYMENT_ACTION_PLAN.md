## 🚨 Если что-то пошло не так

### Ошибка: "Cannot find module 'jsdom'"
**Решение:** Проверить, что коммит `7f1b60bd` применен. Если нет - пересобрать.

### Ошибка: "getRecentBuilds is not a function"
**Решение:** Проверить, что коммит `f5846067` применен. Если нет - пересобрать.

### Dashboard показывает ошибки
**Решение:** 
1. Проверить консоль браузера
2. Проверить логи API (`api/seo-dashboard.js`)
3. Убедиться, что данные доступны

### Страницы не отображаются
**Решение:**
1. Проверить `vercel.json` rewrites
2. Проверить, что страницы сгенерированы в `public/vin/`
3. Проверить логи билда
