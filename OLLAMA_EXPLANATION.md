# 📦 ЧТО ТАКОЕ OLLAMA И КАК ЭТО РАБОТАЕТ

## 🎯 ПРОСТЫМИ СЛОВАМИ

**Ollama** - это готовая программа для Mac (и других систем), которая запускает AI модели локально на твоем компьютере.

---

## 💻 ЧТО ЭТО ТАКОЕ

### Ollama - это:
- ✅ **Готовая программа** для Mac (как любая другая программа)
- ✅ **Бесплатная** (open source)
- ✅ **Оптимизирована** для Apple Silicon (M1/M2/M3)
- ✅ **Работает через командную строку**

### Что она делает:
1. Запускает AI модели локально на Mac
2. Не требует интернета (после загрузки модели)
3. Работает очень быстро (на M1 Neural Engine)

---

## 📥 КАК УСТАНОВИТЬ

### Вариант 1: Через Homebrew (рекомендуется)
```bash
brew install ollama
```

### Вариант 2: Скачать с сайта
1. Иди на https://ollama.ai/download
2. Скачай для Mac
3. Установи как обычную программу

---

## 🚀 КАК РАБОТАЕТ

### 1. Установка Ollama
```bash
brew install ollama
```
**Результат:** Ollama установлена на Mac, работает в фоне

### 2. Загрузка модели
```bash
ollama pull phi3
```
**Результат:** Модель (~2 GB) сохранена на Mac

### 3. Использование
```bash
ollama run phi3 "Напиши текст о VIN отчете"
```
**Результат:** Ollama генерирует текст локально

## 🔧 КАК ЭТО ИНТЕГРИРОВАНО В НАШ КОД

### Наш код делает так:

```javascript
// scripts/seo/ai/local-ai-provider.js

// Вызываем Ollama через команду
const command = `ollama run phi3 "твой промпт"`;
const { stdout } = await execAsync(command);

// Получаем ответ
return stdout; // Готовый текст от AI
```

### Процесс:
1. **Наш код** (Node.js) → вызывает команду `ollama run phi3 "..."`
2. **Ollama** (работает в фоне) → обрабатывает запрос
3. **Ollama** → возвращает текст
4. **Наш код** → использует текст для генерации страницы

### Наш код:
