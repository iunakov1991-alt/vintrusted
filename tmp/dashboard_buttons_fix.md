## 🔍 ДИАГНОСТИКА

### **Проверка в консоли браузера:**

1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Нажмите на кнопку
4. Должны появиться сообщения:
   - `[Dashboard] Start button clicked`
   - `[Dashboard] startOrchestrator called`
   - `[Dashboard] Sending request to /api/orchestrator/start`

### **Если кнопки все еще не работают:**

1. Проверьте, что сервер дашборда запущен:
   ```bash
   npm run monster8:dashboard
   ```

2. Проверьте консоль браузера на ошибки JavaScript

3. Проверьте Network tab в DevTools - идут ли запросы к API

4. Проверьте, что элементы существуют:
   ```javascript
   // В консоли браузера:
   document.getElementById('btn-start')
   document.getElementById('btn-stop')
   ```
