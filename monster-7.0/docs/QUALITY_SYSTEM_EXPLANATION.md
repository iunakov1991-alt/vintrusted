### 2. РАСЧЕТ КАЧЕСТВА (calculateQualityScore)

**НОВАЯ ЛОГИКА:**

```javascript
calculateQualityScore(content) {
  score = 0.0  // Начинаем с 0, нужно заработать каждый балл
  
  // БАЗОВЫЕ (0.15)
  +0.05 если title 30-60 символов
  +0.05 если meta description 120-160
  +0.05 если есть H1
  
  // ДЛИНА КОНТЕНТА (0.15) - КРИТИЧНО!
  +0.15 если >= 3000 слов (гениальный уровень)
  +0.10 если >= 2000 слов
  +0.05 если >= 1500 слов
  -0.20 если < 1000 слов (штраф!)
  
  // СТРУКТУРА (0.20)
  +0.10 если >= 8 основных секций
  +0.10 если >= 5 глубоких секций (300+ слов каждая)
  -0.10 если < 3 секций (штраф!)
  
  // FAQ (0.15)
  +0.10 если >= 10 вопросов
  +0.05 если >= 5 вопросов
  +0.05 если >= 8 длинных ответов (100+ слов)
  -0.05 если нет FAQ (штраф!)
  
  // ЭКСПЕРТНОСТЬ (0.15)
  +0.05 если есть примеры/кейсы
  +0.05 если есть структурированный контент (bullets)
  +0.05 если есть keywords (3+)
  +0.05 если есть internal links (3+)
  
  // ШТРАФЫ
  -0.10 если много коротких секций (< 100 слов)
  -0.05 если нет Introduction
  
  return Math.max(0.0, Math.min(1.0, score))
}
```

**Результат:** Score теперь реально отражает качество!

### 3. ВАЛИДАЦИЯ ПЕРЕД СОХРАНЕНИЕМ

**НОВАЯ ЛОГИКА:**

```javascript
savePages(pages) {
  minQualityThreshold = 0.7  // Минимальный порог
  
  for each page:
    qualityScore = calculateQualityScore(page.content)
    
    if qualityScore < 0.7:
      // АВТОМАТИЧЕСКАЯ РЕГЕНЕРАЦИЯ
      for attempt in [0, 1]:  // До 2 попыток
        regenerated = regenerateLowQualityPage(page, attempt)
        newScore = calculateQualityScore(regenerated)
        
        if newScore >= 0.7:
          page.content = regenerated
          page.qualityScore = newScore
          break
      
      if not regenerated:
        // Все равно сохраняем, но с предупреждением
        console.warn("Low quality after regeneration attempts")
    
    save(page)  // Сохраняем
}
```

**Результат:** Страницы с низким качеством автоматически регенерируются!

### 4. РЕГЕНЕРАЦИЯ

**Процесс:**

1. **Улучшенный промпт:**
   ```
   CRITICAL: Previous generation had low quality.
   You MUST generate GENIUS-LEVEL content with:
   - Minimum 3000 words (current: X words)
   - 8-12 main sections (current: X sections)
   - Each section 300-500 words
   - 10-15 FAQ questions
   - Real examples, case studies, data
   ```

2. **Попытка AI регенерации:**
   - Использует улучшенный промпт
   - Увеличивает maxTokens если нужно
   - Парсит ответ

3. **Fallback: расширенные шаблоны:**
   - Добавляет 3 дополнительные секции
   - Расширяет существующие секции
   - Увеличивает FAQ
