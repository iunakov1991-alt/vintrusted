TITLE TYPES & STATE CONTEXT (ABSTRACT)

COMMON TITLE FLAGS:
- Clean title: no major events recorded.
- Salvage: vehicle considered total loss by insurer.
- Rebuilt / reconstructed: previously salvage, repaired and inspected.
- Junk / parts-only: not intended for road use.
- Lemon buyback (in some states): vehicle repurchased due to defects.

STATE DIFFERENCES:
- Some states are more transparent (disclose more brands).
- Some allow washed titles when vehicle crosses borders.
- Flood, hail, rebuilt, reconstructed labels vary by jurisdiction.

BUYER IMPLICATION:
- Always check how the state defines and records title brands.
