VIN CORE BASICS

- VIN = Vehicle Identification Number (17 characters).
- Contains: WMI (world manufacturer), VDS (vehicle descriptor), VIS (vehicle identifier).
- Used to track:
  - manufacturing data,
  - body/engine type,
  - year, plant,
  - sequence number.

VIN REPORT TYPICALLY COVERS:
- Title history,
- Ownership count,
- Odometer records,
- Accident / damage records,
- Usage type (personal, fleet, rental),
- Salvage / rebuilt / junk events where available.
