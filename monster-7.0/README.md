## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установка зависимостей

```bash
npm install
```

### 2. (Опционально) Настройка локального AI

Если хотите использовать локальный AI (Ollama):

```bash
brew install ollama
ollama pull phi3
```

Затем в `config/monster.config.json`:
```json
{
  "modules": {
    "aiKnowledgeCore": {
      "localAI": true,
      "model": "phi3"
    }
  }
}
```

### 3. Инициализация базы знаний

```bash
# Через API
curl -X POST http://localhost:3000/api/init-knowledge

# Или через Dashboard (кнопка INIT KNOWLEDGE)
```

### 4. Запуск Dashboard

```bash
npm run monster:start
```

### 5. Открытие Dashboard

Откройте в браузере:
```
http://localhost:3000/monster-ui
```

## 🐛 УСТРАНЕНИЕ ПРОБЛЕМ

### Dashboard не запускается

```bash
# Проверьте порт
lsof -i :3000

# Если занят, измените в config/monster.config.json
{
  "dashboard": {
    "port": 3001
  }
}
```

### Модуль не запускается

- Убедитесь, что запускаете через Dashboard
- Проверьте логи в консоли сервера
- Используйте **SELF-REPAIR** для автоматического исправления

### Превышение памяти

- Система автоматически ограничивает использование памяти
- Используйте **STOP** для остановки задач
- Подождите завершения текущих задач
