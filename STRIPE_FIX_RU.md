## ⚠️ ВАЖНО: Настройка переменных окружения в Vercel

Для работы платежной системы необходимо добавить переменные окружения в Vercel:

### Как добавить:

1. Зайдите на **vercel.com**
2. Откройте ваш проект **vintrusted**
3. Перейдите в **Settings** → **Environment Variables**
4. Добавьте следующие переменные:

#### Обязательные переменные:

| Название | Значение | Описание |
|----------|----------|----------|
| `STRIPE_PUBLISHABLE_KEY` | `pk_test_...` или `pk_live_...` | Публичный ключ Stripe |
| `STRIPE_SECRET_KEY` | `sk_test_...` или `sk_live_...` | Секретный ключ Stripe |
| `PRICE_49_EVERY_10D` | `price_...` | ID цены в Stripe для подписки |

**Важно:** Добавьте переменные для всех окружений:
- ✅ Production
- ✅ Preview  
- ✅ Development

### Где взять ключи Stripe:

1. Зайдите на **dashboard.stripe.com**
2. Перейдите в **Developers** → **API keys**
3. Скопируйте:
   - **Publishable key** (начинается с `pk_`)
   - **Secret key** (начинается с `sk_`)
