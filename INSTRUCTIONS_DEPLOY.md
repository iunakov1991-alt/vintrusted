# Пошаговая инструкция по деплою

## Шаг 1: Авторизация в Vercel

Откройте терминал и выполните:

```bash
vercel login
```

Это откроет браузер, где нужно:
1. Войти в свой аккаунт Vercel (или создать новый)
2. Разрешить доступ Vercel CLI

После авторизации вернитесь в терминал.

## Шаг 2: Деплой

После авторизации выполните:

```bash
cd /Users/dmitrii/Desktop/website
vercel --prod --yes
```

Или используйте скрипт:

```bash
./deploy-direct.sh
```

## Альтернатива: Деплой через Vercel Dashboard

Если CLI не работает, можно задеплоить через веб-интерфейс:

1. Зайдите на https://vercel.com
2. Войдите в свой аккаунт
3. Найдите ваш проект
4. Нажмите "Deployments" → "Create Deployment"
5. Или подключите GitHub репозиторий для автоматического деплоя
