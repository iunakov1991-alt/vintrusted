## 🔄 МОДУЛИ (A-I)

### [A] SEMANTIC SCANNER
**Назначение:** Сканирует нишу, строит Semantic Map

**Вход:**
- Домен (vintrusted.com)
- Текущие страницы
- Конкуренты

**Выход:**
- Semantic Map (темы, кластеры, связи)
- Gap анализ
- Конкурентный анализ

**M1 Оптимизация:**
- Легкий парсинг (без тяжелых библиотек)
- Кэширование результатов
- Инкрементальное обновление

---

**Назначение:** Строит стратегию до 1,000,000 страниц

## 🔗 КОММУНИКАЦИЯ МОДУЛЕЙ

Все модули общаются через **MonsterUI Dashboard**:

```
MonsterUI → API → Модуль → Результат → MonsterUI → Отображение
```

**Принцип:**
- Нет прямых вызовов между модулями
- Все через Dashboard API
- Асинхронная обработка
- Очередь задач

## 🎯 M1 ОПТИМИЗАЦИЯ

### Ограничения:
- **RAM:** 8GB (максимум 6GB для процесса)
- **CPU:** 8 ядер (4 performance + 4 efficiency)
- **Диск:** SSD (быстрый, но ограниченный)

### Стратегии:
1. **Легкие процессы:** Минимум зависимостей
2. **Потоковая обработка:** Не загружать все в память
3. **Кэширование:** Сохранять результаты
4. **Батчинг:** Группировать операции
5. **Периодическая очистка:** Освобождать память
6. **Локальный AI:** Ollama вместо API
