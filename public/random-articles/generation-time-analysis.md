## 🔍 Факторы, влияющие на время

### 1. **Количество блоков**
- Больше блоков = больше времени
- Каждый блок требует отдельного AI-вызова
- Параллельная генерация ускоряет процесс

### 2. **Объем контента**
- Больше слов = больше времени на генерацию
- Валидация и retry при ошибках увеличивают время

### 3. **Провайдеры AI**
- **DeepSeek API:** обычно быстрее
- **Ollama (локальный):** может быть медленнее
- Смешанное использование оптимизирует время

### 4. **Сложность темы**
- Специфичные темы (Aston Martin) требуют больше времени
- Стандартные темы (Toyota, Honda) генерируются быстрее
