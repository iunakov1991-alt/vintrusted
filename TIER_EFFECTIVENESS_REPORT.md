```
Premium: $25 / 40% success = $62.50 за успешный $49
```

**Парадокс:** Medium tier дешевле по итоговой цене!

### Но есть нюанс:
- **Premium** = 40% вероятность success → меньше fraud, меньше отходов API
- **Medium** = 18.2% вероятность success → больше fraud, больше отходов

## 🚨 Проблемы Текущей Системы

### 1. Много "Pending" (50%)
- **8 из 16** платежей еще не прошли проверку $49
- Это нормально для молодого проекта
- Через неделю данных будет больше

### 2. Малая Выборка (16 платежей)
- Статистическая погрешность высокая
- Нужно **минимум 100 платежей** для точности
- Пока **тренд положительный**, но могут быть колебания

### 3. Stripe Radar НЕ Используется Полностью
Текущая логика (`api/validate.js`):
```javascript
if (outcome?.risk_level === 'highest') {
  tier = 'fraud'; // $0
}
```

**Проблема:** Игнорируется `risk_level: 'elevated'` и `risk_score`

#### Улучшение:
```javascript
if (outcome?.risk_level === 'highest' || outcome?.risk_score > 75) {
  tier = 'fraud'; // $0 - полностью блокируем
} else if (outcome?.risk_level === 'elevated' || outcome?.risk_score > 50) {
  tier = 'medium'; // $5 - пониженная ставка
} else if (card?.funding === 'credit' && card?.checks?.cvc_check === 'pass') {
  tier = 'premium'; // $25
} else {
  tier = 'medium'; // $5
}
```
