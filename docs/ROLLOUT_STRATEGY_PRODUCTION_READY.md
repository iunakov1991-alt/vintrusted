## 📊 КАК ЭТО РАБОТАЕТ

### **Логика работы:**

1. **Подсчет страниц:**
   ```bash
   EN_COUNT=$(find public/semantic-pages/en -name "index.html" | wc -l)
   ES_COUNT=$(find public/semantic-pages/es -name "index.html" | wc -l)
   ```

2. **Определение фазы:**
   ```bash
   if [ "$EN_COUNT" -lt "$EN_THRESHOLD_FOR_ES" ]; then
     PHASE="en_only"  # Генерируем EN
   else
     PHASE="es_phase"  # Генерируем ES
   fi
   ```

3. **Выбор очереди:**
   - `en_only` → копирует `data/topics_queue.en.json` → `data/topics_queue.json`
   - `es_phase` → копирует `data/topics_queue.es.json` → `data/topics_queue.json`

4. **Запуск генерации:**
   ```bash
   node scripts/build_topics_batch_parallel.js --queue data/topics_queue.json --workers 10
   ```
