## ✅ ЧТО РЕАЛИЗОВАНО

### 1. **Скрипт автоматического деплоя**

**Файл:** `scripts/auto_deploy_page.sh`

**Режимы работы:**
- `single` — деплой одной страницы
- `batch` — деплой всех новых страниц из партии

**Функционал:**
- Автоматическое добавление страниц в git
- Коммит с понятным сообщением
- Push в origin (автоматический деплой через Vercel)
- Обработка ошибок (не критично, если деплой не удался)

---

### 2. **Интеграция в процесс генерации**

**Файл:** `scripts/build_topics_batch_parallel.js`

**Как работает:**
- После успешной генерации партии проверяется `AUTO_DEPLOY`
- Если `AUTO_DEPLOY=1` (по умолчанию), запускается автоматический деплой
- Деплой выполняется в фоне, не блокирует процесс

**Код:**
```javascript
if (success > 0 && process.env.AUTO_DEPLOY === "1") {
  // Запуск автоматического деплоя
  spawnSync("bash", ["scripts/auto_deploy_page.sh", "batch"], ...);
}
```

---

### 3. **Интеграция в оркестратор**

**Файл:** `monster8_orchestrator.sh`

**Как работает:**
- После успешной генерации партии автоматически запускается деплой
- Можно отключить через `AUTO_DEPLOY=0`

**Код:**
```bash
if [ "${AUTO_DEPLOY:-1}" = "1" ]; then
  bash scripts/auto_deploy_page.sh batch
fi
```

## 🎯 ИСПОЛЬЗОВАНИЕ

### **Деплой одной страницы (для теста):**

```bash
bash scripts/auto_deploy_page.sh single "public/semantic-pages/en/dmv-titles/az/title-types/checklist/index.html"
```

### **Деплой всех новых страниц:**


```bash
DRY_RUN=1 bash scripts/auto_deploy_page.sh batch
```

## 🔄 ПРОЦЕСС РАБОТЫ

### **При генерации партии:**

1. Генерация страниц через `build_topics_batch_parallel.js`
2. После успешной генерации проверяется `AUTO_DEPLOY`
3. Если включен → автоматический деплой всех новых страниц
4. Git add → commit → push
5. Vercel автоматически задеплоит страницы

### **При генерации одной страницы:**

1. Генерация через `build_topic_page.sh`
2. Ручной деплой через `auto_deploy_page.sh single`
