# 📊 ВЫБОРОЧНЫЙ АНАЛИЗ КАЧЕСТВА ДЛЯ САМООБУЧЕНИЯ

**Дата:** 2025-12-06  
**Статус:** ✅ **РЕАЛИЗОВАНО**

---

## 🎯 ЦЕЛЬ

Автоматически анализировать качество сгенерированных страниц после каждой партии для самообучения системы.

---

## 📋 КАК РАБОТАЕТ

### 1. **Автоматический запуск после генерации батча**

После успешной генерации партии страниц система автоматически:
1. Сканирует недавно созданные страницы (в пределах 1 часа)
2. Выбирает выборочно страницы по разным направлениям
3. Анализирует качество выбранных страниц
4. Сохраняет результаты для самообучения

### 2. **Выборка по разным направлениям**

Система выбирает страницы для анализа по следующим критериям:

- **Языки:** По одной странице из каждого языка (EN/ES)
- **Штаты:** По одной странице из каждого штата (AZ, CA, TX, FL, NY и т.д.)
- **Типы тем:** По одной странице из каждого типа темы (dmv-titles, vin-check, accident-history и т.д.)
- **Уровни глубины:** По одной странице с разной глубиной вложенности URL
- **Случайные:** Остальные страницы выбираются случайно до достижения целевого количества

### 3. **Количество страниц для анализа**

- **Минимум:** 3 страницы в батче для запуска анализа
- **Целевое количество:** 20% от успешных страниц (минимум 5, максимум 10)
- **Примеры:**
  - 10 страниц → 2 страницы (но минимум 5, поэтому 5)
  - 30 страниц → 6 страниц
  - 100 страниц → 10 страниц (максимум)

## 🔧 КОНФИГУРАЦИЯ

### Переменные окружения:

- `ENABLE_QUALITY_ANALYSIS` - Включить/выключить анализ (по умолчанию: включен)
  - `"0"` - отключить анализ
  - любое другое значение или отсутствие - включить

### Параметры анализа:

В `scripts/batch_quality_analysis.js` можно настроить:

```javascript
const analysisOptions = {
  maxAge: 3600000,        // Максимальный возраст страниц для анализа (1 час)
  targetCount: 10,        // Целевое количество страниц для анализа
  minPagesForAnalysis: 3 // Минимум страниц в батче для запуска анализа
};
```

### Сохранение результатов:

## 🔄 ИНТЕГРАЦИЯ С САМООБУЧЕНИЕМ

Результаты анализа автоматически используются системой самообучения:

1. **Метрики качества** сохраняются в `data/seo/quality_logs/quality_analysis.jsonl`
2. **Система RL** (`scripts/rl_ingest_metrics.js`) читает эти метрики
3. **Стратегия обновляется** на основе результатов анализа
4. **Следующие генерации** улучшаются на основе полученных данных

## ✅ ПРЕИМУЩЕСТВА

1. **Автоматизация:** Не требует ручного вмешательства
2. **Выборочность:** Анализирует достаточное количество для проверки, но не все страницы
3. **Разнообразие:** Выборка по разным направлениям обеспечивает репрезентативность
4. **Эффективность:** Анализ происходит до деплоя, локально
5. **Самообучение:** Результаты автоматически применяются к улучшению следующих генераций

## 🎯 ИСПОЛЬЗОВАНИЕ

## 🔍 ПРИМЕРЫ

### Пример 1: Батч из 30 страниц

- **Сгенерировано:** 30 страниц
- **Выбрано для анализа:** 6 страниц (20% от 30)
- **Направления:**
  - 2 страницы (EN/ES)
  - 5 страниц (разные штаты: AZ, CA, TX, FL, NY)
  - 3 страницы (разные типы тем)
  - 1 страница (разная глубина)

### Пример 2: Батч из 5 страниц

- **Сгенерировано:** 5 страниц
- **Выбрано для анализа:** 5 страниц (минимум 5, но все доступны)
- **Направления:** Все страницы анализируются

### Пример 3: Батч из 100 страниц

- **Сгенерировано:** 100 страниц
- **Выбрано для анализа:** 10 страниц (максимум 10)
- **Направления:** Максимальное разнообразие по всем критериям
