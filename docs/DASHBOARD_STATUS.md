## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### 1. Секция может быть не видна из-за:

- **CSS скрывает** - проверить `display: none` или `visibility: hidden`
- **Вне видимой области** - прокрутить страницу вниз
- **JavaScript не обновляет** - проверить консоль на ошибки

### 2. API `/api/batch-status` возвращает 404:

- Endpoint не задеплоен
- Нужно проверить `vercel.json` и задеплоить изменения
