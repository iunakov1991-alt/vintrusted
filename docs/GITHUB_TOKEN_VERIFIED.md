## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### Проблема: Вижу инструкции для локального запуска вместо "✅ Партия запущена"

**Возможные причины:**
1. Токен не имеет права `workflow`
2. Токен не имеет права `repo`
3. Workflow файл не существует
4. Неправильный репозиторий

**Решение:**
1. Проверьте права токена: https://github.com/settings/tokens
2. Убедитесь, что токен имеет scopes: `repo` и `workflow`
3. Проверьте, что файл `.github/workflows/monster8-batch-scheduler.yml` существует
4. Проверьте логи в Vercel Functions для деталей ошибки

### Проблема: Workflow запускается, но падает с ошибкой

**Решение:**
1. Проверьте GitHub Secrets: https://github.com/iunakov1991-alt/vintrusted/settings/secrets/actions
2. Убедитесь, что `DEEPSEEK_API_KEY` настроен
3. Проверьте логи workflow: https://github.com/iunakov1991-alt/vintrusted/actions
