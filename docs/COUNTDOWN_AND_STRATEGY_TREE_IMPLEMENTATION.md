# ⏰ Обратный отсчет и дерево стратегии

**Дата:** 2025-12-06  
**Статус:** ✅ **РЕАЛИЗОВАНО**

---

## ✅ РЕАЛИЗОВАННЫЕ ФУНКЦИИ

### 1. ⏰ Обратный отсчет времени до следующей партии

**Что добавлено:**
- Обратный отсчет в реальном времени до следующей запланированной партии
- Отображение в формате: `Xд Xч Xм Xс` или `Xч Xм Xс` или `Xм Xс` или `Xс`
- Автоматическое обновление каждую секунду
- Автоматическая перезагрузка расписания после истечения времени

**Где отображается:**
- В секции "📅 Расписание партий"
- Под заголовком "Следующая партия"

**Функции:**
- `startCountdown(nextBatch)` - запускает обратный отсчет
- `stopCountdown()` - останавливает обратный отсчет
- `updateCountdown()` - обновляет отображение каждую секунду

---

### 2. 📋 Превью следующей партии

**Что добавлено:**
- Автоматическое отображение превью следующей партии после запуска текущей
- Показывает:
  - Количество страниц
  - Язык
  - Длительность
  - Штаты (если есть)
  - Зоны (если есть)
  - Форматы (если есть)

**Где отображается:**
- В секции "📅 Расписание партий"
- Под обратным отсчетом

**Функции:**
- `updateNextBatchPreview(nextBatch)` - загружает и отображает превью

---

### 3. 🌳 Дерево стратегии

**Что добавлено:**
- Кнопка "🌳 Дерево стратегии" в секции расписания
- Модальное окно с полным деревом всех тем
- Структура: Zone → State → Format → Language → Topics
- Подсветка пройденных тем (✅ задеплоено, ⏳ ожидает)
- Статистика: всего тем, задеплоено, зон

**Где отображается:**
- Модальное окно (открывается по кнопке)
- Полноэкранный режим с прокруткой

**Функции:**
- `loadStrategyTree()` - загружает дерево стратегии с сервера
- `renderStrategyTree(treeData)` - отрисовывает дерево в HTML
- `showStrategyTreeModal()` - открывает модальное окно
- `closeStrategyTreeModal()` - закрывает модальное окно

**API Endpoint:**
- `GET /api/strategy/tree` - возвращает дерево стратегии

**Backend Script:**
- `scripts/build_strategy_tree.js` - строит дерево из всех тем

## ✅ ИНТЕГРАЦИЯ

**Автоматическое обновление:**
- Обратный отсчет запускается автоматически при загрузке расписания
- Превью следующей партии загружается автоматически
- Дерево стратегии загружается при открытии модального окна

**WebSocket события:**
- `batch:completed` - перезагружает расписание и запускает новый отсчет

**API интеграция:**
- `GET /api/batch/schedule` - получает следующую партию
- `POST /api/batch/preview` - получает превью партии
- `GET /api/strategy/tree` - получает дерево стратегии

## 🎯 РЕЗУЛЬТАТ

**После запуска новой партии:**
1. ✅ Автоматически показывается обратный отсчет до следующей партии
2. ✅ Автоматически показывается превью следующей партии
3. ✅ Можно открыть дерево стратегии для просмотра всех тем

**Дерево стратегии показывает:**
- ✅ Все темы в порядке приоритетов
- ✅ Подсветку пройденного пути (задеплоенные темы)
- ✅ Статистику по темам
