# 📊 УЛУЧШЕННАЯ АДАПТИВНАЯ СТРАТЕГИЯ С УЧЕТОМ ПРОДА

**Дата:** 2025-12-06  
**Статус:** ✅ **ОБНОВЛЕНО**

---

## 🎯 ПРОБЛЕМА СТАРОЙ ВЕРСИИ

**Старая адаптивная стратегия** учитывала только:
- ⏰ Время с последней партии

**Не учитывала:**
- ❌ Количество страниц на проде
- ❌ Разницу между локальным и продом
- ❌ Потребность в заполнении прода

**Результат:** Если на проде мало страниц (1), но последняя партия была недавно, размер партии был маленьким (50%), хотя нужно больше!

---

## ✅ НОВАЯ УЛУЧШЕННАЯ СТРАТЕГИЯ

**Новая адаптивная стратегия** учитывает:
1. ⏰ **Время с последней партии** (как раньше)
2. 📊 **Количество страниц на проде** (НОВОЕ!)

---

## 📋 КАК РАБОТАЕТ

### Шаг 1: Расчет по времени (как раньше)

| Время с последней партии | Базовый размер |
|-------------------------|----------------|
| < 12 часов | 50% от максимума (50 страниц) |
| 12-24 часа | 75% от максимума (75 страниц) |
| ≥ 24 часа | 100% от максимума (100 страниц) |

### Шаг 2: Корректировка по проду (НОВОЕ!)

| Страниц на проде | Множитель | Логика |
|------------------|-----------|--------|
| **< 10** | **2.0x** | Очень мало - увеличиваем в 2 раза |
| **10-50** | **1.5x** | Мало - увеличиваем на 50% |
| **50-200** | **1.0x** | Нормально - без изменений |
| **≥ 200** | **0.9x** | Много - можно немного уменьшить |

### Шаг 3: Финальный расчет

```
Размер партии = min(максимум, базовый_размер × множитель_прод)
Минимум: 5 страниц
```

---

## 📊 ПРИМЕРЫ РАБОТЫ

### Пример 1: Мало на проде (1), недавняя партия (6ч)

**Базовый расчет:**
- Время: 6 часов → 50 страниц (50%)

**Корректировка:**
- На проде: 1 страница → множитель 2.0x

**Итого:**
- 50 × 2.0 = **100 страниц** (максимум)

**Результат:** Даже при недавней партии, если на проде мало страниц, размер максимальный!

---

### Пример 2: Мало на проде (1), давняя партия (30ч)

**Базовый расчет:**
- Время: 30 часов → 100 страниц (100%)

**Корректировка:**
- На проде: 1 страница → множитель 2.0x

**Итого:**
- 100 × 2.0 = **100 страниц** (максимум, ограничен)

**Результат:** Максимальный размер для заполнения прода.

---

### Пример 3: Средне на проде (50), недавняя партия (6ч)

**Базовый расчет:**
- Время: 6 часов → 50 страниц (50%)

**Корректировка:**
- На проде: 50 страниц → множитель 1.5x

**Итого:**
- 50 × 1.5 = **75 страниц**

**Результат:** Увеличенный размер для продолжения заполнения.

---

### Пример 4: Много на проде (200), недавняя партия (6ч)

**Базовый расчет:**
- Время: 6 часов → 50 страниц (50%)

**Корректировка:**
- На проде: 200 страниц → множитель 0.9x

**Итого:**
- 50 × 0.9 = **45 страниц**

**Результат:** Немного уменьшенный размер, так как на проде уже достаточно.

## 🔍 ДЕТАЛЬНАЯ ЛОГИКА

### Код из `scripts/batch_scheduler.js`:

```javascript
function calculateNextBatchParams(lastBatch, strategy) {
  // ... расчет времени ...
  
  // Получаем количество страниц на проде
  const deployedPages = getDeployedPagesCount();
  
  // Базовый расчет по времени
  let timeBasedSize = strategy.maxPagesPerBatch;
  if (hoursSinceLastBatch < 12) {
    timeBasedSize = Math.floor(strategy.maxPagesPerBatch * 0.5);
  } else if (hoursSinceLastBatch < 24) {
    timeBasedSize = Math.floor(strategy.maxPagesPerBatch * 0.75);
  }
  
  // Корректировка на основе страниц на проде
  let productionMultiplier = 1.0;
  if (deployedPages < 10) {
    productionMultiplier = 2.0;  // Увеличиваем в 2 раза
  } else if (deployedPages < 50) {
    productionMultiplier = 1.5;   // Увеличиваем на 50%
  } else if (deployedPages < 200) {
    productionMultiplier = 1.0;   // Без изменений
  } else {
    productionMultiplier = 0.9;   // Немного уменьшаем
  }
  
  batchSize = Math.min(
    strategy.maxPagesPerBatch,
    Math.max(5, Math.floor(timeBasedSize * productionMultiplier))
  );
}
```

## ✅ ПРЕИМУЩЕСТВА

1. **Учитывает прод:** Размер партии зависит от количества страниц на проде
2. **Заполняет прод:** Если на проде мало страниц, размер увеличивается
3. **Балансирует нагрузку:** Если на проде много страниц, размер немного уменьшается
4. **Минимум:** Всегда минимум 5 страниц, даже при маленьких расчетах

- Базовый: 100 страниц (≥ 24 часов)

## ✅ ЗАКЛЮЧЕНИЕ

Теперь адаптивная стратегия **учитывает количество страниц на проде** и автоматически увеличивает размер партии, если на проде мало страниц, даже если последняя партия была недавно!

**Это решает проблему:** Система будет активно заполнять прод, когда там мало страниц! 🎯
