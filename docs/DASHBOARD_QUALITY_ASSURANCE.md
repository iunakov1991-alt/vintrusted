## 🛡️ МЕХАНИЗМЫ ЗАЩИТЫ

### 1. **Инвалидация кэша при действиях**
```javascript
// При запуске/остановке оркестратора
apiCache.timestamps['orchestrator'] = 0;
apiCache.timestamps['status'] = 0;
```

### 2. **WebSocket события обходят кэш**
```javascript
socket.on('status:update', (data) => {
  // Обновляем напрямую, инвалидируем кэш
  updateDashboard(data);
  setCached('status', data);
});
```

### 3. **Принудительное обновление при подключении**
```javascript
socket.on('connect', () => {
  loadStatus(true);  // force = true
  loadOrchestratorStatus(true);
});
```

### 4. **Fallback на кэш только при ошибках**
```javascript
catch (err) {
  const cached = getCached('status');
  if (cached) return cached;  // Только если ошибка
}
```
