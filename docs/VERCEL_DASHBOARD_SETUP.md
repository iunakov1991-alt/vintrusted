## 📊 API ENDPOINTS

Все API endpoints доступны через `/dashboard/api/...`:

- `GET /dashboard/api/status` - статус системы
- `GET /dashboard/api/strategy/tree` - дерево стратегии
- `POST /dashboard/api/batch/preview` - превью партии
- `GET /dashboard/api/batch/schedule` - расписание партий
- `GET /dashboard/api/batch/history` - история партий

---

## 🔧 КАК РАБОТАЕТ

1. **Запрос к `/dashboard`** → возвращает HTML
2. **HTML загружает JS** → JS автоматически определяет базовый URL
3. **API запросы** → идут на `/dashboard/api/...`
4. **Статические файлы** → загружаются из `/dashboard/dashboard-8.0.css` и `/dashboard/dashboard-8.0.js`
