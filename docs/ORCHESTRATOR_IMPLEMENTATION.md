## 🔧 РЕАЛИЗОВАННЫЕ ФУНКЦИИ

### **1. Определение фазы языков** ✅

**Логика:**
- **en_only:** EN < 100 страниц → генерируем только EN
- **mixed:** EN >= 100, ES < 50 → основной батч EN, ES фоном
- **es_focus:** EN >= 100, ES >= 50 → фокус на ES

**Код:**
```bash
detect_language_phase() {
  if [ "$en_pages" -lt "$EN_THRESHOLD_FOR_ES" ]; then
    echo "en_only"
  elif [ "$es_pages" -lt "$ES_HARD_MIN" ]; then
    echo "mixed"
  else
    echo "es_focus"
  fi
}
```

---

### **2. Day/Night режимы** ✅

**Логика:**
- **Day (short):** 6:00 - 22:00 → короткий контент, больше воркеров
- **Night (long):** 22:00 - 6:00 → длинный контент, меньше воркеров

**Настройка:**
```bash
NIGHT_START_HOUR=22  # Начало ночи
NIGHT_END_HOUR=6     # Конец ночи
```

---

### **3. Latency мониторинг** ✅

**Логика:**
- Измеряет latency DeepSeek и Ollama API
- Адаптирует количество воркеров:
  - Если DeepSeek > 3 сек → воркеры / 2
  - Если Ollama > 3 сек → воркеры - 2
  - Минимум: 2 воркера

**Защита:**
- Если DeepSeek latency >= 4 сек → батч не запускается

---

### **4. Адаптивные воркеры** ✅

**Логика:**
- **Day:** 10 воркеров (по умолчанию)
- **Night:** 6 воркеров (по умолчанию)
- **С учетом latency:** Динамически уменьшается при медленном API

## ⚠️ ОГРАНИЧЕНИЯ

### **1. BPG (Background Prep) - отключен**
**Причина:** Требует доработки `build_topics_batch.js` для поддержки:
- `--mode=background`
- `--delay-ms`
- `--length-mode`
- `--skip-render`
- `--skip-validate`

**Решение:** Можно включить после доработки батч-скрипта.

### **2. Length mode - не используется**
**Причина:** Текущий батч не поддерживает `--length-mode` параметр.

**Решение:** Можно добавить в будущем для настройки длины контента.
