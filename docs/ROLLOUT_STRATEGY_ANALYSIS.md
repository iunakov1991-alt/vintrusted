# 📊 АНАЛИЗ: СТРАТЕГИЯ ROLLOUT EN/ES НА ПРОДАКШЕНЕ

**Дата:** 2025-12-06  
**Вопрос:** Будет ли работать приоритет английских текстов для старта?

---

## ✅ ДА, СТРАТЕГИЯ РАБОТАЕТ!

### **Как это работает:**

1. **Приоритет EN контента:**
   - Система сначала генерирует английские страницы
   - Порог по умолчанию: **50 EN страниц** перед стартом ES
   - Можно настроить через `EN_THRESHOLD_FOR_ES`

2. **Автоматическое переключение:**
   - Когда EN страниц >= порога → переключается на ES
   - Использует `data/topics_queue.en.json` для EN
   - Использует `data/topics_queue.es.json` для ES

3. **Стратегический подход:**
   - Сначала покрываем EN рынок (больше трафика)
   - Затем добавляем ES для расширения аудитории
   - Контролируемый рост контента

---

## 🔧 ТЕКУЩАЯ СИТУАЦИЯ

### **Статистика:**
- **EN страниц:** 7
- **ES страниц:** 3
- **Порог для ES:** 50 страниц

### **Текущая стратегия:**
- ✅ **Генерируем EN** (7 < 50)
- ⏸️ **ES на паузе** (ждем 50 EN страниц)

---

## 📋 КАК ЭТО РАБОТАЕТ НА ПРОДАКШЕНЕ

### **1. Запуск rollout:**
```bash
./monster8_en_es_rollout.sh
```

### **2. Логика работы:**
```bash
# Подсчет EN страниц
EN_COUNT=$(find public/semantic-pages/en -name "index.html" | wc -l)

# Проверка порога
if [ "$EN_COUNT" -lt "$EN_THRESHOLD_FOR_ES" ]; then
  # Генерируем EN
  cp data/topics_queue.en.json data/topics_queue.json
else
  # Генерируем ES
  cp data/topics_queue.es.json data/topics_queue.json
fi

# Запуск генерации
node scripts/build_topics_batch_parallel.js --queue data/topics_queue.json
```

### **3. Настройка порога:**
```bash
# Через переменную окружения
export EN_THRESHOLD_FOR_ES=100
./monster8_en_es_rollout.sh

# Или в скрипте напрямую
EN_THRESHOLD_FOR_ES=100 ./monster8_en_es_rollout.sh
```

- ✅ Можно настроить порог под свои нужды

## ⚠️ РЕКОМЕНДАЦИИ ДЛЯ ПРОДАКШЕНА

### **1. Начальный этап (первые 100 страниц):**
- ✅ **Фокус на EN:** Генерируйте только английские страницы
- ✅ **Порог:** Установите `EN_THRESHOLD_FOR_ES=100` или выше
- ✅ **Цель:** Покрыть основные темы на английском

### **2. Расширение (100+ страниц):**
- ✅ **Добавление ES:** Когда EN контент стабилен
- ✅ **Порог:** Снизьте до `EN_THRESHOLD_FOR_ES=50`
- ✅ **Цель:** Расширить аудиторию на испанском рынке

### **3. Оптимизация:**
- ✅ **Мониторинг:** Отслеживайте количество страниц каждого языка
- ✅ **Баланс:** Поддерживайте соотношение EN:ES (например, 2:1)
- ✅ **Качество:** Не жертвуйте качеством ради количества
