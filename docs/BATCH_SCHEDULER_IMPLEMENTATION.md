## ✅ ЧТО РЕАЛИЗОВАНО

### 1. **Планировщик партий (`scripts/batch_scheduler.js`)**

**Функционал:**
- ✅ Автоматическое планирование следующей партии после успешного деплоя
- ✅ Вычисление параметров партии (размер, язык, время)
- ✅ Учет стратегии (интервалы, предпочтительное время, размер партии)
- ✅ История партий (последние 50)

**Стратегии размера партии:**
- `fixed` — фиксированный размер
- `adaptive` — адаптивный (зависит от времени с последней партии)
- `progressive` — прогрессивное увеличение

**Конфигурация:** `config/batch-strategy.json`

**Новые endpoints:**
- `GET /api/batch/schedule` — получить расписание

- `POST /api/batch/start` — запустить партию с превью
- `POST /api/batch/complete` — отметить партию как завершенную

## 🔄 КАК РАБОТАЕТ

### **Автоматическое планирование:**

1. После успешного деплоя партии вызывается `POST /api/batch/complete`
2. Планировщик:
   - Добавляет завершенную партию в историю
   - Вычисляет параметры следующей партии
   - Планирует следующую партию согласно стратегии
   - Сохраняет в `data/batch-schedule.json`

### **Вычисление времени следующей партии:**

- Учитывает минимальный интервал между партиями
- Выбирает ближайшее предпочтительное время
- Если минимальный интервал не прошел — использует его + предпочтительное время

### **Вычисление размера партии:**

- **Adaptive:** зависит от времени с последней партии
  - < 12 часов: 50% от максимума
  - < 24 часа: 75% от максимума
  - >= 24 часа: 100% от максимума
- **Progressive:** увеличивается с каждой партией
- **Fixed:** всегда максимальный размер

## 📋 ИСПОЛЬЗОВАНИЕ

### **Запуск партии из дашборда:**

1. Нажать кнопку "🚀 Start Batch"
2. Просмотреть превью с параметрами
3. Подтвердить или отменить

### **Просмотр расписания:**

- Расписание автоматически обновляется каждые 2 секунды
- Показывает ближайшую партию с напоминанием

### **Просмотр истории:**

- История загружается автоматически при открытии дашборда
- Можно обновить вручную кнопкой "Refresh"
- Можно выбрать количество (10/20/50)

## 🔧 ИНТЕГРАЦИЯ С ОРКЕСТРАТОРОМ

**После успешного деплоя партии:**

```bash
# В monster8_orchestrator.sh после успешного деплоя:
# Вызывать API для отметки партии как завершенной
curl -X POST http://localhost:3001/api/batch/complete \
  -H "Content-Type: application/json" \
  -d '{
    "batchId": "batch-123",
    "result": {
      "pagesGenerated": 50,
      "pagesDeployed": 50,
      "language": "en"
    }
  }'
```

**Или через Node.js:**

```javascript
const batchScheduler = require('./scripts/batch_scheduler');
batchScheduler.markBatchCompleted(batchId, result);
```
