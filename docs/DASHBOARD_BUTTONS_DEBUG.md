## 🔍 ДИАГНОСТИКА

### **Шаг 1: Проверка консоли браузера**

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Console**
3. Нажмите на кнопку
4. Должны появиться сообщения:
   ```
   [Dashboard] Start button clicked
   [Dashboard] startOrchestrator called
   [Dashboard] Sending request to /api/orchestrator/start
   ```

### **Шаг 2: Проверка элементов**

В консоли браузера выполните:
```javascript
// Проверка наличия элементов
document.getElementById('btn-start')
document.getElementById('btn-stop')
document.getElementById('btn-start-batch')

// Проверка обработчиков
document.getElementById('btn-start').onclick
```

### **Шаг 3: Проверка Network**

1. Откройте DevTools → **Network**
2. Нажмите на кнопку
3. Должен появиться запрос к `/api/orchestrator/start` или `/api/orchestrator/stop`

### **Шаг 4: Проверка сервера**

Убедитесь, что сервер дашборда запущен:
```bash
npm run monster8:dashboard
```

Или проверьте:
```bash
pgrep -f "server-8.0.js"
```

## 🐛 ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### **Проблема 1: Элементы не найдены**

**Симптом:** В консоли ошибка `Cannot read property 'addEventListener' of null`

**Решение:** 
- Проверьте, что HTML загружен полностью
- Убедитесь, что скрипт загружается после HTML

### **Проблема 2: Запросы не отправляются**

**Симптом:** В Network нет запросов

**Решение:**
- Проверьте, что сервер запущен
- Проверьте URL в `API_BASE` (должен быть пустым для относительных путей)

### **Проблема 3: Кнопки перекрыты**

**Симптом:** Кнопки видны, но не кликабельны

**Решение:**
- Проверьте CSS на наличие `pointer-events: none`
- Проверьте `z-index` элементов
