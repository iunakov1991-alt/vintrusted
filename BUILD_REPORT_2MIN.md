## 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1. **Локальный AI не работает**
**Ошибка:** `Error: unknown flag: --num-predict`

**Причина:** 
- Команда `ollama run` не поддерживает флаг `--num-predict`
- Неправильный синтаксис команды в `local-ai-provider.js`

**Последствия:**
- Все попытки вызова локального AI провалились
- Система автоматически переключилась на API (DeepSeek/Groq)
- Потеря преимуществ локального AI (скорость, отсутствие лимитов)

**Исправление:** ✅ Исправлено в коде (используется `echo` для передачи промпта)

---

### 2. **Критическое использование памяти**
**Ошибка:** `Memory usage critical: 91.2%` → `Maximum call stack size exceeded`

**Причина:**
- Слишком агрессивная генерация (15,000 страниц)
- Memory Monitor входит в бесконечный цикл очистки
- Накопление объектов в памяти

**Последствия:**
- Билд упал с ошибкой переполнения стека
- Невозможность завершить генерацию

**Рекомендации:**
- Уменьшить целевой объем до 5,000-10,000 страниц
- Увеличить частоту очистки памяти
- Добавить принудительный GC после каждых 1,000 страниц

---

### 3. **M1 Optimizer не активирован**
**Проблема:** Не видно логов о детекции M1 и использовании 6 потоков

**Ожидалось:**
```
[SEO M1-OPTIMIZER] Detected MacBook M1. Setting optimal concurrency to 6
```

**Фактически:**
- Конкуренция осталась на уровне 10 потоков (из config)
- M1 Optimizer не сработал

**Причина:** Возможно, проверка `isM1()` не сработала или код не выполнился

---

### 4. **Seed Analyzer ошибка**
**Ошибка:** `existingCoverage.combinations.has is not a function`

**Причина:** 
- `combinations` не является `Set` или `Map`
- Неправильная структура данных в `seed-analyzer-generator.js`

**Последствия:**
- Seed Expansion использовал fallback (300 страниц)
- AI Decision переопределил до 15,000 страниц
