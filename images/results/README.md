This folder contains images for the results screen tabs. Please replace the placeholder images with your actual images:

## Required Images:

1. **odometer-history.png** - Odometer History chart showing mileage over time

## Image Requirements:
- Format: PNG or JPG
- Recommended size: 400x300px or similar aspect ratio
- Background: White or transparent
- Quality: High resolution for clear display

## How to Replace:
1. Save your images with the exact filenames listed above
2. Place them in this folder (`images/results/`)
3. The website will automatically use the new images
