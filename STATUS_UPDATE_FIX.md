# 🔍 ПРОБЛЕМА: Статус партии показывает нули

## ❌ ПРОБЛЕМА

Статус партии не обновляется в дашборде, показывает все нули.

## 🔍 ПРИЧИНЫ

1. **GitHub Actions обновляет статус через API** → сохраняет в `/tmp/batch-status.json`
2. **Дашборд читает статус через API** → читает из `/tmp/batch-status.json`
3. **НО:** В Vercel каждая serverless функция имеет свой изолированный `/tmp`
4. **Результат:** Статус, сохраненный одной функцией, недоступен другой функции

## ✅ РЕШЕНИЕ

Нужно использовать **один endpoint** для чтения и записи статуса, или использовать **внешнее хранилище**.

### Вариант 1: Использовать один endpoint
- `/api/batch-status` для чтения И записи
- Дашборд читает из `/api/batch-status` (GET)
- GitHub Actions пишет в `/api/batch-status` (POST)

### Вариант 2: Использовать внешнее хранилище
- Vercel KV (Redis)
- Vercel Postgres
- Или просто использовать один endpoint с in-memory хранилищем

## 🚀 БЫСТРОЕ РЕШЕНИЕ

Использовать `/api/batch-status` для чтения статуса в дашборде вместо `/api/batch-runner/status`.
