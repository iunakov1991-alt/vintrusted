ПРОСТАЯ ИНСТРУКЦИЯ ПО ДЕПЛОЮ
================================

Проблема: Автоматические команды зависают из-за большого количества файлов.

РЕШЕНИЕ: Используйте GitHub Desktop или веб-интерфейс GitHub

ВАРИАНТ 1: ЧЕРЕЗ GITHUB DESKTOP (САМЫЙ ПРОСТОЙ)
------------------------------------------------
1. Откройте GitHub Desktop
2. Вы увидите все изменения
3. Напишите сообщение коммита: "Deploy all: 24,000 articles + pagination"
4. Нажмите "Commit to main"
5. Нажмите "Push origin"
6. Vercel автоматически задеплоит!

ВАРИАНТ 2: ЧЕРЕЗ GITHUB ВЕБ-ИНТЕРФЕЙС
--------------------------------------
1. Откройте https://github.com/iunakov1991-alt/vintrusted
2. Нажмите "Upload files"
3. Перетащите папку articles2/ и файл vercel.json
4. Напишите коммит: "Deploy all: 24,000 articles"
5. Нажмите "Commit changes"
6. Vercel автоматически задеплоит!

ВАРИАНТ 3: ЧЕРЕЗ ТЕРМИНАЛ (если не зависает)
---------------------------------------------
Откройте терминал и выполните по одной команде:

cd /Users/dmitrii/Desktop/website

git add vercel.json
git add public/sitemap.xml
git add articles2-list.json

# Затем добавляйте папку articles2 (может занять время):
git add articles2/

# Создайте коммит:
git commit -m "Deploy all: 24,000 articles + pagination"

# Отправьте:
git push

ВАРИАНТ 4: ЧЕРЕЗ VERCEL DASHBOARD
----------------------------------
1. Зайдите на https://vercel.com
2. Найдите ваш проект
3. Нажмите "Deployments" → "Create Deployment"
4. Загрузите файлы или подключите напрямую
