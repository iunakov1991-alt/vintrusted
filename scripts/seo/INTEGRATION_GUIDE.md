# SEO Monster 6.0 — Руководство по интеграции метрик

## 0. Google Analytics Integration (Автоматическая)

Google Analytics автоматически интегрирован во все SEO страницы.

**Настройка:**
- По умолчанию используется ID: `G-CX3CT2K2FC`
- Можно изменить через переменную окружения: `GOOGLE_ANALYTICS_ID`
- Или через конфиг: `data/seo/config.json` → `googleAnalyticsId`

**Что отслеживается:**
- Просмотры страниц (pageviews)
- Время на странице (time on page)
- Показатель отказов (bounce rate)
- События (если настроены)

**Использование данных:**
- Данные автоматически собираются в Google Analytics
- Для импорта метрик используйте утилиту `metrics-import.js` (см. раздел 3)
- Система самообучения использует эти метрики для оптимизации

## 1. Google Search Console Integration

### Импорт данных из GSC

**Шаг 1: Экспорт данных из Google Search Console**
1. Перейдите на https://search.google.com/search-console
2. Выберите ваш property (vintrusted.com)
3. Перейдите в **Performance > Search Results**
4. Настройте фильтры:
   - Date range: последние 3-6 месяцев
   - Query: можно оставить пустым или фильтровать по "vin"
   - Page: фильтр `/vin/` для SEO страниц
5. Нажмите **Export** и скачайте CSV или JSON

**Шаг 2: Импорт данных**
```bash
# CSV формат
node scripts/seo/utils/gsc-import.js --csv path/to/gsc-export.csv

# JSON формат
node scripts/seo/utils/gsc-import.js --json path/to/gsc-export.json
```

**Формат CSV должен содержать колонки:**
- URL или Page
- Clicks
- Impressions
- CTR
- Position (или Average Position)

**Что происходит после импорта:**
- Данные сохраняются в `data/seo/gsc-cache.json`
- При следующем билде страницы обогащаются метриками из GSC
- Weight Engine использует реальные CTR и позиции вместо quality scores
- Веса intent'ов, языков и layout'ов обновляются на основе реальных данных

## 2. A/B Testing

### Создание A/B теста

A/B тесты создаются автоматически для страниц с высоким трафиком или вручную через API.

**Типы вариантов:**
1. **Layout** — изменение структуры страницы
2. **Title** — альтернативные заголовки
3. **CTA** — разные призывы к действию
4. **Content Order** — изменение порядка блоков

**Метрики для сравнения:**
- Views (просмотры)
- Clicks (клики)
- Conversions (конверсии)
- Bounce Rate (показатель отказов)
- Time on Page (время на странице)

**Score формула:**
```
score = CTR × 0.3 + Conversion Rate × 0.4 + (1 - Bounce Rate) × 0.2 + Time Score × 0.1
```

**Автоматическое применение победителя:**
После завершения теста (минимум 100 просмотров) победитель автоматически применяется к основной странице.

## 3. External Metrics (Google Analytics)

### Импорт данных из Google Analytics

**Шаг 1: Экспорт данных из GA4**
1. Перейдите в ваш GA4 property
2. Перейдите в **Reports > Engagement > Pages and screens**
3. Настройте фильтры:
   - Page path содержит `/vin/`
   - Date range: последние 3-6 месяцев
4. Экспортируйте данные как CSV или JSON

**Шаг 2: Импорт данных**
```bash
# CSV формат
node scripts/seo/utils/metrics-import.js --csv path/to/analytics-export.csv

# JSON формат
node scripts/seo/utils/metrics-import.js --json path/to/analytics-export.json
```

**Формат данных должен содержать:**
- URL или Page Path
- Bounce Rate
- Average Time on Page (или Avg. Session Duration)
- Sessions (опционально)
- Pageviews (опционально)

**Что происходит после импорта:**
- Данные сохраняются в `data/seo/external-metrics.json`
- При следующем билде страницы обогащаются метриками
- Weight Engine учитывает bounce rate и time on page при обновлении весов
- Страницы с низким bounce rate и высоким time on page получают больший приоритет

## Как это работает вместе

### Цикл самообучения с реальными метриками:

1. **Билд #1:**
   - Генерируются страницы
   - Используются quality scores для обучения

2. **После билда:**
   - Импортируются данные из GSC (CTR, позиции)
   - Импортируются данные из GA (bounce rate, time on page)
   - Данные сохраняются в кеш

3. **Билд #2:**
   - Страницы обогащаются метриками из GSC и GA
   - Weight Engine использует реальные метрики:
     - CTR из GSC (40% веса)
     - Position из GSC (40% веса)
     - Bounce Rate из GA (20% веса)
     - Time on Page из GA (15% веса)
   - Веса обновляются на основе реальных данных
   - Система автоматически находит лучшие комбинации

4. **Билд #3 и далее:**
   - Система продолжает учиться на реальных метриках
   - Оптимизирует генерацию страниц под реальные результаты

## Рекомендации

### Частота импорта данных:
- **GSC:** раз в неделю или раз в месяц
- **GA:** раз в неделю или раз в месяц
- Импорт можно автоматизировать через cron или GitHub Actions

### Минимальные требования:
- Для эффективного обучения нужно минимум 100-200 страниц с данными
- Чем больше данных, тем точнее обучение

### Приоритет метрик:
1. **GSC CTR** — самый важный показатель (40%)
2. **GSC Position** — важный для ранжирования (40%)
3. **GA Bounce Rate** — качество контента (20%)
4. **GA Time on Page** — вовлеченность (15%)

## Файлы данных

После импорта создаются файлы:
- `data/seo/gsc-cache.json` — кеш данных из GSC
- `data/seo/gsc-data.json` — полные данные импорта
- `data/seo/external-metrics.json` — метрики из аналитики
- `data/seo/rl-state.json` — обновляется автоматически после каждого билда

## Troubleshooting

**Проблема:** Импорт не находит URL'ы
- **Решение:** Убедитесь, что URL'ы в экспорте содержат `/vin/` и соответствуют формату `/vin/:vin/:state/`

**Проблема:** Веса не обновляются
- **Решение:** Проверьте, что данные импортированы и страницы обогащены метриками перед этапом LTR Update

**Проблема:** Нет данных для большинства страниц
- **Решение:** Это нормально для новых страниц. Система будет использовать quality scores до появления реальных данных
