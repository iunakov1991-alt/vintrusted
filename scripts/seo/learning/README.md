# 🤖 Self-Learning Loop System

Система самообучения AI через итеративную генерацию и улучшение статей.

## 🎯 Как это работает

1. **Итерация 0**: Генерирует статью БЕЗ обучения (базовая версия)
2. **Итерации 1-10**: 
   - Генерирует статью С обучением
   - Анализирует качество
   - Обновляет стратегию на основе результатов
   - Регенерирует статью с улучшенной стратегией
3. **Результат**: Создает страницу сравнения всех версий

## 🚀 Использование

### Запуск цикла обучения

```bash
# Запустить с 10 итерациями (по умолчанию)
node scripts/seo/learning/run-learning-loop.js

# Запустить с другим количеством итераций
node scripts/seo/learning/run-learning-loop.js 15
```

### Просмотр результатов

После завершения цикла откройте в браузере:

```
http://localhost:3000/learning-loop/comparison.html
```

## 📊 Что генерируется

### Структура файлов

```
public/learning-loop/
├── comparison.html          # Страница сравнения всех версий
├── article-v0.html          # Версия 0 (без обучения)
├── article-v1.html          # Версия 1 (с обучением)
├── article-v2.html          # Версия 2 (улучшенная)
├── ...
└── article-v10.html         # Версия 10 (финальная)
```

### Метрики качества

Каждая версия оценивается по:
- **Word Count**: Количество слов
- **Quality Score**: Общий балл качества (0-1)
- **Structure**: Наличие структуры (заголовки, списки)
- **Expert Tone**: Экспертный тон
- **Actionable Advice**: Практические советы
- **Semantic Coverage**: Покрытие семантических тиров

## 🔄 Процесс обучения

### Итерация 0 (Без обучения)
- AI генерирует статью без использования обученной стратегии
- Базовое качество без оптимизации

### Итерации 1-10 (С обучением)
1. Загружается текущая стратегия из `learned-strategy.json`
2. Промпт обогащается знаниями из стратегии
3. Генерируется статья с учетом обучения
4. Анализируется качество статьи
5. Обновляется стратегия через `updateStrategyFromResults()`
6. Следующая итерация использует улучшенную стратегию

## 📈 Ожидаемые результаты

- **v0**: Базовое качество без обучения (~0.3-0.5)
- **v1-3**: Начальное обучение, улучшение структуры (~0.5-0.7)
- **v4-6**: Средний уровень, улучшение тона (~0.7-0.85)
- **v7-9**: Высокий уровень, экспертность (~0.85-0.95)
- **v10**: Мастерский уровень (~0.9-1.0)

## 🎨 Страница сравнения

Страница сравнения показывает:
- Градацию качества по версиям
- Ссылки на все версии статей
- Метрики каждой версии
- Визуальный прогресс обучения

## ⚙️ Настройка

### Изменение темы статьи

Отредактируйте `context` в методах:
- `generateArticleWithoutTraining()`
- `generateArticleWithTraining()`

### Изменение критериев качества

Отредактируйте метод `calculateQualityScore()` для изменения весов метрик.

### Изменение количества итераций

Передайте параметр при запуске:
```bash
node scripts/seo/learning/run-learning-loop.js 20
```

## 📝 Логи

Все действия логируются с префиксом `[SELF-LEARNING]`:
- Генерация статей
- Применение обучения
- Обновление стратегии
- Сохранение версий

## 🔍 Анализ результатов

После завершения цикла проверьте:
1. Страницу сравнения для визуального анализа
2. Файлы статей для детального сравнения
3. Обновленную стратегию в `data/seo/ai-training/learned-strategy.json`
