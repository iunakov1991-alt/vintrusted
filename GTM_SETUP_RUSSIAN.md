## 📋 ЧТО НУЖНО НАСТРОИТЬ В GTM

### 1️⃣ GOOGLE ADS CONVERSION TAG (для конверсий в Google Ads)

#### Шаг 1: Создать триггер для события 'conversion'
1. Зайди в GTM → **Триггеры** → **Создать**
2. **Название триггера**: `Conversion Event`
3. **Тип триггера**: `Специальное событие`
4. **Название события**: `conversion`
5. **Сохранить**

#### Шаг 2: Создать Google Ads Conversion тег
1. Зайди в GTM → **Теги** → **Создать**
2. **Название тега**: `Google Ads Conversion - Purchase`
3. **Тип тега**: `Отслеживание конверсий Google Ads`
4. **Настройки**:
   - **Идентификатор конверсии**: `17824079146`
   - **Ярлык конверсии**: `l62hCKPTndgbEKq6I7NC`
   - **Ценность конверсии**: выбери "Использовать переменную данных" → создай переменную `value` из dataLayer
   - **Валюта**: `USD`
   - **Идентификатор заказа**: создай переменную `transaction_id` из dataLayer
5. **Триггер**: выбери `Conversion Event` (созданный выше)
6. **Сохранить**

---

### 2️⃣ GOOGLE ANALYTICS 4 TAG (для аналитики)

#### Шаг 1: Создать переменную GA4 Measurement ID
1. Зайди в GTM → **Переменные** → **Создать**
2. **Название**: `GA4 Measurement ID`
3. **Тип**: `Константа`
4. **Значение**: `G-ТВОЙ_ID` (найди в GA4: Администратор → Потоки данных → Measurement ID)

#### Шаг 2: Создать GA4 Configuration тег
1. Зайди в GTM → **Теги** → **Создать**
2. **Название тега**: `GA4 Configuration`
3. **Тип тега**: `Конфигурация Google Аналитики: GA4`
4. **Идентификатор отслеживания**: выбери переменную `{{GA4 Measurement ID}}`
5. **Настройки полей**:
   - Добавь поле `ab_variant` со значением `{{ab_variant}}` (переменная уже создана)
6. **Триггер**: `All Pages` (все страницы)
7. **Сохранить**

#### Шаг 3: Создать триггер для события 'purchase'
1. Зайди в GTM → **Триггеры** → **Создать**
2. **Название триггера**: `Purchase Event`
3. **Тип триггера**: `Специальное событие`
4. **Название события**: `purchase`
5. **Сохранить**

#### Шаг 4: Создать GA4 Event тег для покупок
1. Зайди в GTM → **Теги** → **Создать**
2. **Название тега**: `GA4 Event - Purchase`
3. **Тип тега**: `Событие Google Аналитики: GA4`
4. **Идентификатор конфигурации**: выбери тег `{{GA4 Configuration}}`
5. **Название события**: `purchase`
6. **Параметры события**:
   - `transaction_id` → переменная из dataLayer
   - `value` → переменная из dataLayer (или константа `3`)
   - `currency` → константа `USD`
   - `vin` → переменная из dataLayer
   - `ab_variant` → переменная `{{ab_variant}}`
7. **Триггер**: выбери `Purchase Event` (созданный выше)
8. **Сохранить**

## 🧪 ТЕСТИРОВАНИЕ

### Как проверить что работает:

1. **Режим Preview в GTM**:
   - В GTM нажми **Preview**
   - Введи URL: `https://vintrusted.com`
   - Сделай тестовую покупку
   - Проверь что теги сработали:
     - `Google Ads Conversion - Purchase`
     - `GA4 Event - Purchase`
     - `GA4 Event - POKUPKA`

2. **Консоль браузера**:
   - Открой DevTools (F12) → Console
   - Сделай покупку
   - Должны появиться логи:
     ```
     [CONFIRMATION] ✅ Google Ads conversion event pushed to dataLayer (variant: light)
     [CONFIRMATION] ✅ GA4 purchase event pushed to dataLayer (variant: light)
     [CONFIRMATION] ✅ GA4 POKUPKA event pushed to dataLayer (variant: light)
     ```

3. **Google Analytics DebugView**:
   - В GA4: Настройка → DebugView
   - Сделай покупку
   - Должно появиться событие `purchase` с параметрами

4. **Google Ads**:
   - Проверь через 24-48 часов
   - Google Ads → Конверсии
   - Должна появиться конверсия

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### GA4 не показывает данные:
- Проверь что GA4 Configuration тег срабатывает на All Pages
- Проверь Measurement ID правильный
- Проверь в DebugView (может быть задержка до 24 часов для обычных отчетов)

### Google Ads конверсии не приходят:
- Проверь Conversion ID и Label правильные
- Проверь что тег Google Ads срабатывает в Preview Mode
- Конверсии могут появиться с задержкой до 48 часов
- Проверь что в Google Ads импортированы конверсии из GA4 (если используешь)

### События не отправляются:
- Открой консоль браузера
- Посмотри ошибки CSP (должны быть исправлены)
- Проверь что `window.dataLayer` существует
- Проверь логи: `console.log('[CONFIRMATION] ✅ ...')`
