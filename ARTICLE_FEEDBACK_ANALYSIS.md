## 🔴 КРИТИЧНЫЕ ПРОБЛЕМЫ

### 1. Фактические ошибки

#### 1.1. VIN Decoder - НЕПРАВИЛЬНО

**Ошибка:**
```
4T: Toyota Kentucky, 1: country of origin (USA)
```

**Правильно:**
- `4` = США (страна)
- `T` = Toyota (производитель)
- `1` = Тип транспортного средства (passenger car), НЕ страна

**Ошибка в примере VIN:**
- Пример: `4T1BF1FK3FU123456`
- Позиция 10 должна быть `J` для 2018 года, а не `3`
- Перемешаны позиции в VIS блоке

**Действие:** Полностью переписать VIN decoder с правильным примером

---

#### 1.2. WMI Противоречие

**Ошибка в FAQ:**
```
"WMI (JTM for Toyota Motor Manufacturing, Kentucky)"
```

**Правильно:**
- Для Camry 2018: `4T1`, а не `JTM`
- `JTM` используется для других моделей/заводов

**Действие:** Исправить FAQ, убрать JTM для Kentucky

---

#### 1.3. Smog Check - Противоречие

**Проблема:**
- В Key Facts: "Access smog check certification history"
- Позже: "smog pass/fail репорты не попадают в отчёт"

**Факт:**
- Коммерческие VIN-репорты НЕ дают полноценный BAR smog-лог
- Максимум — косвенные данные по регистрации

**Действие:** Унифицировать информацию, убрать противоречия
