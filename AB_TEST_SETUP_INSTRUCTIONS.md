# 🎯 A/B Test Setup для Главной Страницы

## Что делает система:

1. **50/50 ротация** между светлой и темной версиями hero-секции
2. **Cookie на 30 дней** - пользователь всегда видит одну версию  
3. **Отслеживание в GTM/GA4** - полная аналитика по вариантам
4. **Отслеживание конверсий** - понимаете, какая версия конвертирует лучше

---

## 📊 Отслеживание конверсий

### В dataLayer отправляется:

**При загрузке страницы:**
```javascript
{
  event: 'ab_test_view',
  ab_variant: 'light' // или 'dark'
}
```

**При клике на "Get My Report":**
```javascript
{
  event: 'ab_test_click',
  ab_variant: 'light' // или 'dark'
}
```

**При покупке (уже настроено в purchase-confirmation.html):**
```javascript
{
  event: 'purchase',
  ab_variant: 'light', // или 'dark'
  value: 3.00,
  currency: 'USD'
}
```

---

## 🔧 Настройка в GTM

### Шаг 1: Создать переменную

**Название:** `AB Test Variant`  
**Тип:** Data Layer Variable  
**Имя переменной в Data Layer:** `ab_variant`

### Шаг 2: Добавить вариант во все конверсионные события

В тег "Google Ads Conversion" добавить:
- **Custom Parameter:** `ab_variant`  
- **Значение:** `{{AB Test Variant}}`

В тег "GA4 Purchase Event" уже будет автоматически передаваться `ab_variant` из dataLayer.

### Шаг 3: Создать пользовательский отчет в GA4

**События для отслеживания:**
- `ab_test_view` - просмотры вариантов
- `ab_test_click` - клики на форму
- `purchase` - покупки

**Сегментация:** по параметру `ab_variant`

---

## 📈 Метрики для анализа

| Метрика | Как посчитать |
|---------|---------------|
| **CTR на форму** | `ab_test_click / ab_test_view * 100%` |
| **Conversion Rate** | `purchases / ab_test_view * 100%` |
| **Revenue** | Сумма `value` в событиях `purchase` |
| **CPA** | `Ad Spend / purchases` |

---

## 🎯 Как определить победителя

**Минимум данных:** 100 конверсий на вариант (или 1000 посетителей)

**Статистическая значимость:** используйте калькулятор A/B теста:
- https://www.optimizely.com/ab-testing-calculator/

**Рекомендация:** Тестируйте минимум 2 недели для учета дневных/недельных колебаний

## 🔍 Проверка работы

1. Откройте `https://vintrusted.com/` в режиме инкогнито
2. Откройте Chrome DevTools → Console
3. Введите: `document.cookie`
4. Должна быть: `ab_variant=light` или `ab_variant=dark`
5. Обновите страницу - вариант должен остаться тем же
6. Откройте DevTools → Network → найдите запрос к GTM
7. Проверьте, что `ab_variant` передается

---

## ⚠️ Важно

- Не меняйте пропорции (50/50) во время теста
- Не меняйте дизайн версий во время теста
- Не останавливайте тест раньше времени
- Учитывайте сезонность и внешние факторы
