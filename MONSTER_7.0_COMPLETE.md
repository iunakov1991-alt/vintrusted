## 📋 ОБЗОР

Monster 7.0 — это полностью автономная, самообучающаяся SEO-машина, спроектированная для работы на MacBook Air M1 8GB. Система генерирует до 1,000,000 SEO-оптимизированных страниц, используя внутренний AI, обученный на документации Google, TRIZ принципах и enterprise best practices.

### Ключевые принципы:

- ✅ **Легкая** — оптимизирована для M1 8GB
- ✅ **Автономная** — работает без постоянного вмешательства
- ✅ **Самообучающаяся** — учится на лучших результатах
- ✅ **Самопочиняющаяся** — использует TRIZ для решения проблем
- ✅ **Управляемая через Dashboard** — единственная точка входа

## 🏗️ АРХИТЕКТУРА

### Модули (A-I):

1. **[A] Semantic Scanner** — Сканирование ниши, построение Semantic Map
2. **[B] Strategy Generator** — Построение стратегии до 1M страниц
3. **[C] Prompt Engine** — Генерация "божественных" промтов
4. **[D] Evolution Engine** — Саморазвитие системы
5. **[E] TRIZ Repair** — Самопочинка по TRIZ (40 принципов)
6. **[F] Library Scanner** — Обновление библиотек
7. **[G] AI Knowledge Core** — Внутренний AI с базой знаний
8. **[H] Dashboard** — Единственная точка запуска
9. **[I] Performance Learner** — Обучение на лучших результатах

- **Content Generator** — Генерация SEO-контента с AI
- **Self-Questions Generator** — Генерация вопросов для человека
- **Report Generator** — Генерация отчетов (JSON/HTML/Markdown)

### Утилиты:

- **Logger** — Централизованная система логирования
- **SystemMonitor** — Мониторинг системы (память, CPU, задачи)
- **Orchestrator** — Оркестрация всех модулей

## 🚀 ЗАПУСК

### 1. Установка

```bash
npm install
```

### 2. (Опционально) Настройка локального AI

```bash
brew install ollama
ollama pull phi3
```

### 3. Инициализация базы знаний

```bash
# Через API
curl -X POST http://localhost:3000/api/init-knowledge

# Или через Dashboard (кнопка INIT KNOWLEDGE)
```

### 4. Запуск Dashboard

```bash
npm run monster:start
```

### 5. Открытие Dashboard

```
http://localhost:3000/monster-ui
```

## 🔗 API ENDPOINTS

### Статус и мониторинг:

- `GET /api/status` — Статус системы
- `GET /api/metrics` — История метрик
- `GET /api/logs` — Последние логи

### Управление:

- `POST /api/start` — Запуск полного цикла
- `POST /api/stop` — Остановка всех задач
- `POST /api/module/:moduleName` — Запуск отдельного модуля

### Данные:

- `GET /api/tasks` — Все задачи
- `GET /api/task/:taskId` — Статус задачи
- `GET /api/reports` — Список отчетов

### Специальные:

- `POST /api/init-knowledge` — Инициализация базы знаний
- `POST /api/export-report` — Экспорт отчета
- `POST /api/feedback` — Human Feedback Loop

## 🐛 УСТРАНЕНИЕ ПРОБЛЕМ

### Dashboard не запускается

```bash
# Проверьте порт
lsof -i :3000

# Измените порт в config/monster.config.json
{
  "dashboard": {
    "port": 3001
  }
}
```

### Модуль не запускается

- Убедитесь, что запускаете через Dashboard
- Проверьте логи: `GET /api/logs`
- Используйте **SELF-REPAIR** для автоматического исправления

### Превышение памяти

- Система автоматически ограничивает использование
- Используйте **STOP** для остановки задач
- Проверьте метрики: `GET /api/metrics`
