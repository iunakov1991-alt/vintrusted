# 📋 План процесса генерации SEO страниц Monster 7.0

## ⏱️ Оценка времени

### Общая оценка для одной страницы (3000+ слов):

| Этап | Время | Описание |
|------|-------|----------|
| **1. Инициализация** | 1-2 сек | Загрузка модулей, конфигов, правил |
| **2. Генерация промпта** | 2-5 сек | Создание промпта с учетом обучения |
| **3. AI генерация контента** | **8-15 минут** | ⚠️ **САМЫЙ ДОЛГИЙ ЭТАП** - Ollama генерирует 3000+ слов |
| **4. Парсинг ответа** | 1-2 сек | Извлечение JSON из ответа AI |
| **5. Валидация качества** | 2-5 сек | Проверка качества контента |
| **6. Построение HTML** | 1-2 сек | Создание HTML страницы |
| **7. Сохранение файла** | 0.5-1 сек | Запись на диск |
| **ИТОГО** | **8-16 минут** | В зависимости от скорости Ollama |

### Для нескольких страниц:

- **1 страница**: 8-16 минут
- **5 страниц**: 40-80 минут (1-1.5 часа)
- **10 страниц**: 80-160 минут (1.5-2.5 часа)

⚠️ **ВАЖНО**: Генерация происходит **последовательно**, не параллельно, чтобы не перегружать M1.

## 🔄 Детальный план процесса

### Этап 1: Инициализация (1-2 сек)
```
✓ Загрузка config/monster.config.json
✓ Загрузка data/knowledge/generation-rules.json
✓ Инициализация ContentGenerator
✓ Инициализация PromptEngine
✓ Инициализация AIKnowledgeCore
✓ Инициализация LocalAIProvider (Ollama)
```

### Этап 2: Генерация промпта (2-5 сек)
```
✓ Загрузка master prompt из monster-7.0/core/prompts/master-seo-prompt.js
✓ Применение правил из generation-rules.json
✓ Обогащение промпта знаниями из AI Knowledge Core
✓ Добавление контекста (тема, ключевые слова, intent)
✓ Формирование финального промпта (3000-5000 символов)
```

### Этап 3: AI генерация контента (8-15 минут) ⚠️
```
✓ Проверка доступности Ollama
✓ Создание временного файла для длинного промпта (>4000 символов)
✓ Запуск команды: cat temp_file.txt | ollama run phi3
✓ Ожидание ответа (таймаут: 15 минут)
✓ Очистка ANSI escape codes из ответа
✓ Извлечение текста из ответа
✓ Удаление временного файла
```

**Почему так долго?**
- Ollama на M1 генерирует ~2-5 токенов/сек для phi3
- Для 3000+ слов нужно ~4000-5000 токенов
- 4000 токенов / 3 токена/сек = ~1333 секунд = ~22 минуты (теоретически)
- На практике: 8-15 минут (зависит от сложности промпта и модели)

### Этап 4: Парсинг ответа (1-2 сек)
```
✓ Поиск JSON в ответе AI (regex: /\{[\s\S]*\}/)
✓ Парсинг JSON
✓ Нормализация секций:
  - Удаление "undefined" значений
  - Обработка FAQ секций (content = '')
  - Обработка scenario секций
  - Обработка таблиц
✓ Валидация структуры
```

### Этап 5: Валидация качества (2-5 сек)
```
✓ Подсчет слов в контенте
✓ Подсчет разделов
✓ Подсчет FAQ вопросов
✓ Проверка наличия таблиц
✓ Проверка наличия сценариев
✓ Проверка технических терминов
✓ Проверка отсутствия "fluff"
✓ Расчет quality score (0-1)
✓ Если score < 0.7: автоматическая регенерация (до 2 попыток)
```

### Этап 6: Построение HTML (1-2 сек)
```
✓ Применение стандартного дизайна (seo-page-template.css)
✓ Генерация header с навигацией
✓ Генерация hero section
✓ Генерация main content (секции)
✓ Генерация FAQ section
✓ Генерация footer
✓ Добавление inline CSS
✓ Добавление мета-тегов (title, description, canonical)
```

### Этап 7: Сохранение файла (0.5-1 сек)
```
✓ Создание директории: public/seo-pages/{page-slug}/
✓ Сохранение HTML: public/seo-pages/{page-slug}/index.html
✓ Обновление статистики страниц
✓ Логирование результата
```

## 🐛 Известные проблемы и исправления

### Проблема 1: Таймаут 5 минут недостаточен
**Исправление**: Увеличен таймаут до 15 минут (900000 мс)
- Файл: `scripts/seo/ai/local-ai-provider.js`
- Строка 14: `this.timeout = parseInt(process.env.LOCAL_AI_TIMEOUT || '900000', 10);`

### Проблема 2: Длинные промпты вызывают ошибки shell
**Исправление**: Использование временного файла для промптов >4000 символов
- Файл: `scripts/seo/ai/local-ai-provider.js`
- Строки 47-55: Создание temp файла
- Строка 61: `cat "${tempFilePath}" | ollama run ${this.model}`

### Проблема 3: ANSI escape codes в ответе Ollama
**Исправление**: Очистка ANSI кодов из stdout
- Файл: `scripts/seo/ai/local-ai-provider.js`
- Строки 99-109: Множественные replace() для очистки

### Проблема 4: "undefined" в FAQ секциях
**Исправление**: Нормализация секций при парсинге
- Файл: `monster-7.0/core/modules/content-generator.js`
- Строки 466-473: Обработка FAQ секций

## ⚙️ Оптимизации для ускорения

### Вариант 1: Уменьшить требования к длине (не рекомендуется)
- Снизить minWords с 3000 до 2000
- Снизить minSections с 8 до 6
- **Минус**: Качество контента снизится

### Вариант 2: Использовать более быструю модель
- Заменить `phi3` на `llama3.2:1b` (быстрее, но хуже качество)
- Или `qwen2.5:0.5b` (очень быстро, но низкое качество)
- **Минус**: Качество контента значительно снизится

### Вариант 3: Генерация по частям (рекомендуется для будущего)
- Генерировать разделы отдельно
- Генерировать FAQ отдельно
- Объединять результаты
- **Плюс**: Можно параллелизировать
- **Минус**: Требует рефакторинга кода

### Вариант 4: Использовать streaming (для будущего)
- Ollama поддерживает streaming через API
- Получать ответ по частям
- **Плюс**: Можно показывать прогресс
- **Минус**: Требует рефакторинга на использование Ollama API вместо CLI
