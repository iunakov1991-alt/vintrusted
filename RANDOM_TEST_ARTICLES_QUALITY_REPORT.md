**Проблема:** Во всех статьях используется WMI "1HG" (Honda), но статьи написаны про разные производители:
- Статья 2: Suzuki XL-7 → WMI должен быть для Suzuki
- Статья 3: McLaren 600LT → WMI должен быть для McLaren
- Статья 4: Pagani Utopia → WMI должен быть для Pagani
- Статья 5: Isuzu i-280 → WMI должен быть для Isuzu

**Причина:** Генератор использует фиксированный пример VIN с WMI "1HG" вместо генерации правильного VIN для каждого производителя.

**Решение:** Необходимо генерировать правильные VIN для каждого производителя или использовать универсальные примеры без привязки к конкретному WMI.
